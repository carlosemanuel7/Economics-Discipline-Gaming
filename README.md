# 🎮 Economics Game

A game developed in **C++** for the **Economics** course, designed to apply economic concepts in a practical and interactive way.

## 📚 About the Project

This game is being developed as an academic project, using programming to represent situations and concepts related to economics.

Throughout the game, the player will make decisions that can affect their resources, income, expenses, and overall results. This allows economic concepts to be explored through an interactive experience.

## 🎯 Objectives

- Apply concepts studied in the Economics course;
- Develop a game using C++;
- Encourage decision-making and logical reasoning;
- Demonstrate economic concepts in an interactive way;
- Practice programming concepts and code organization.

## 🧠 Economic Concepts

The game aims to represent economic concepts studied in the course, such as:

- Supply and demand;
- Price;
- Consumption;
- Production;
- Profit and loss;
- Resource scarcity;
- Inflation;
- Investments;
- Economic decision-making.

The concepts used may be adjusted according to the topics covered in the course.
